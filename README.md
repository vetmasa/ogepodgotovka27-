# Сайт «Подготовка к ОГЭ по русскому языку · 9 класс · 2027»

Минималистичный серый сайт. Не требует сборки: откройте `index.html` в браузере.

Основная навигация состоит из **6 страниц**. Страница «Учебники» дополнительно ведёт внутрь каждого учебника — там собраны оглавления, соответствие параграфов заданиям и ссылки на источники. На страницах учебников есть изображения обложек для сличения со своим экземпляром.

## Страницы

| Файл | Содержание |
|---|---|
| `index.html` | Обзор экзамена: задания 2–12, таблица баллов по каждому заданию (всего 11), бланк № 1, изменения 2027, документы ФИПИ |
| `tasks.html` | Задания 2–12: формулировки, алгоритмы, фильтр по типу, таблица баллов, точные ссылки `#task2`–`#task12` |
| `theory.html` | Справочник: фонетика, лексика, морфология, синтаксис, пунктуация, орфография, анализ текста |
| `textbooks.html` | Подборка учебников 9 класса с обложками и переходы на подробные страницы; на каждой странице есть кнопки онлайн-чтения или скачивания |
| `practice.html` | Тренажёр: по 50 усложнённых заданий на каждое из заданий 2–12 (550 всего), проверка, подсказки, кнопка «Видеоразбор» и сохранение прогресса |
| `plan.html` | 8-недельный план с вкладками: в каждой неделе есть задания-ссылки на тренажёр и теорию, галочки сохраняются в браузере |

Подробные страницы учебников лежат в `books/`: `trostentsova.html`, `barhudarov.html`, `razumovskaya.html`, `deikina.html`, `panov.html`, `bystrova.html`.

## Что важно

- Сайт охватывает только **задания 2–12** тестовой части (11 баллов, бланк № 1). Задания 1 и 13 не рассматриваются.
- Любое упоминание письменной части есть только в нижней примечании: «Письменная часть (сжатое изложение и сочинение-рассуждение) — в разработке».
- Точные формулировки заданий, баллы и изменения 2027 года сверены с официальными документами ФИПИ.
- Соответствие параграфов учебников заданиям ОГЭ указано **ориентировочно**: нумерация зависит от издания. Для Панова и Быстровой, где полные оглавления недоступны, указаны укрупнённые разделы и темы.

## Как редактировать

### Способ 1 — прямо в браузере (без знаний HTML)
1. Откройте нужную страницу.
2. Нажмите кнопку **«Редактировать»** в правом нижнем углу.
3. Нажимайте на любой текст с пунктирной рамкой и меняйте его.
4. Нажмите **«Сохранить»** — правки сохранятся в этом браузере.
5. Нажмите **«Скачать HTML»**, чтобы получить готовый файл страницы с вашими правками.
6. **«Сбросить»** возвращает исходный текст.

### Способ 2 — в файлах
- Весь текст лежит непосредственно в HTML-файлах внутри тегов с атрибутами `data-editable` — меняйте его в любом текстовом редакторе.
- Цвета, шрифты и отступы задаются в `assets/styles.css` в блоке `:root`.
- Поведение меню, фильтров и режима редактирования — в `assets/app.js`.
- Банк усложнённых заданий — `assets/practice-data.js` (исходная версия сохранена в `practice-data-base.js`), логика проверки и прогресса — `assets/practice.js`, ссылки на видео — `assets/practice-video.js`. Прогресс хранится в `localStorage` браузера, сброс — кнопкой «Сбросить задание». Портал РЭШ приостановлен с 01.06.2026, поэтому видеоразборы ведут на открытые уроки с рабочими ссылками.
